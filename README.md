# لوح الشرح — نسخة قابلة للتثبيت (PWA)

برنامج شرح مباشر بين المعلم والطلاب (شرائح، رسم، امتحان). يُنشر على GitHub Pages ثم يُثبَّت على الحاسوب أو الهاتف ويعمل بلا اتصال.

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` | البرنامج نفسه |
| `manifest.webmanifest` + `icons/` | اسم التطبيق وأيقوناته للتثبيت |
| `sw.js` | يحفظ البرنامج على الجهاز ليعمل بلا إنترنت |
| `libs/` | المكتبات والخطوط. ملفات قارئ PDF مرفقة، وبقية المكتبات والخطوط تُنزَّل تلقائيًا (انظر الخطوة 2) |
| `download-libs.sh` / `.bat` | تنزيل المكتبات يدويًا |
| `.github/workflows/pages.yml` | نشر تلقائي على GitHub Pages مع تنزيل المكتبات |

## النشر على GitHub (الطريقة التلقائية — مستحسنة)
1. أنشئ مستودعًا جديدًا **عامًا (Public)** ثم ارفع كل محتويات هذا المجلد إليه (Add file ← Upload files).
   إن لم يظهر مجلد `.github` بعد الرفع: اختر Add file ← Create new file، واكتب الاسم `.github/workflows/pages.yml` والصق محتوى الملف.
2. من Settings ← Pages ← Source اختر **GitHub Actions**.
3. من تبويب Actions انتظر اكتمال «Deploy to GitHub Pages» (دقيقة تقريبًا). ينزّل تلقائيًا المكتبات (PeerJS و QRCode و jsQR) والخطوط إلى `libs/` ثم ينشر.
4. رابط البرنامج: `https://اسم-المستخدم.github.io/اسم-المستودع/`

### بدون Actions (يدويًا)
شغّل `download-libs.bat` (ويندوز) أو `bash download-libs.sh` (ماك/لينكس) مرة واحدة بوجود إنترنت، ثم ارفع المجلد كاملًا بما فيه `libs/`، واختر في Pages: Deploy from a branch ← main.

## التثبيت
- **أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق»، أو زر «تثبيت البرنامج» في شاشة الدخول.
- **آيفون / آيباد (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **حاسوب (Chrome / Edge):** أيقونة التثبيت في شريط العنوان.

## العمل بلا إنترنت
- افتح البرنامج **مرة واحدة بوجود إنترنت** ليحفظ نفسه على الجهاز؛ بعدها يفتح بلا اتصال.
- الاتصال بين المعلم والطلاب يحتاج خادم إشارة: إما الإنترنت (الافتراضي)، أو خادم محلي على شبكة الواي فاي بلا إنترنت (من «إعدادات الشبكة» داخل البرنامج: `npx peerjs --port 9000`).
- مع البرنامج المثبَّت عند الجميع اختر في نافذة QR: «الرمز فقط»، فيمسحه الطالب من داخل البرنامج.

## التحديث
عند رفع نسخة جديدة غيّر رقم الإصدار في `sw.js` (`lawh-v1` ← `lawh-v2`) لتُحمَّل التحديثات على الأجهزة.

## استيراد PDF و PowerPoint
زر «رفع صور» (أو السحب والإفلات على اللوح) يقبل الآن صورًا و **PDF** و **pptx**؛ كل صفحة/شريحة تصبح شريحة يمكن الرسم عليها.
- **PDF:** يُعرض بدقة كاملة. قارئ PDF (pdf.js) مرفق في `libs/`.
- **pptx:** يُرسم داخل المتصفح: النصوص والصور والأشكال والجداول والخلفيات. لا تُعرض المخططات ورسوم SmartArt والتدرجات المعقدة، وقد تختلف الخطوط والمسافات قليلًا. للحصول على شكل مطابق احفظ العرض من PowerPoint كـ PDF ثم استورده.
- صيغة ppt القديمة غير مدعومة: احفظها كـ pptx أو PDF.
- استيراد PDF بلا إنترنت يعمل عند تشغيل البرنامج من الموقع المنشور أو بعد تثبيته، لا من فتح الملف مباشرة من المجلد.
